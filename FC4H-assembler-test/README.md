# FastCall4Help 组装器测试包

这是 FC4H 当前的最小可测试版本，用于模拟“旗舰被抓”时的信息自动组装和复制到剪贴板。

## 使用方式

1. 打开 `index.html`。
2. 填写或点击“填入示例”。
3. 点击“组装并复制”。
4. 到任意文本框中粘贴，检查生成的求救信息。

## 代码阅读入口

- `assembler.js`：逻辑层的信息组装器，包含事件创建、敌情原型判断、最终消息格式。
- `app.js`：页面交互和剪贴板复制。

## 当前消息格式

```text
[FC4H][旗舰被抓]
驾驶员：...
位置：...
舰船：...
血量：盾 ...% / 甲 ...% / 结构 ...%
敌对：... 人，...
判断：...
信号：...
备注：...
时间：...
```

## 当前边界

- 当前字段以手动填写或模拟自动读取为主。
- 敌对人数、敌对舰船类型和备注已经预留 AI 输入接口。
- 当前原型规则：黑诱导保留黑隐队 / T3队 / 常规 / 无畏可能；白诱导暂排除 T3队和黑隐队。
- 如果只有前置车头且主力尚未进场，消息会标记“主力未知”。
- QQ 群机器人和游戏内自动发送暂未接入。
