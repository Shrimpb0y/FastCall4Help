# FastCall4Help 轻量测试包

FC4H 当前版本改为轻量求救消息：只组装本地日志较容易获得的信息。

## 使用方式

1. 打开 `index.html`。
2. 选择最新的 `本地_*.txt` 日志；舰队日志可选。
3. 如果日志没有读到某项，可以手动补填。
4. 点击“一键求救”。
5. 页面会自动组装消息并复制到剪贴板，由用户粘贴到游戏内或其他频道。

## 当前消息格式

```text
[FC4H][被抓]
被抓人员：...
当前地点：...
所在舰队：...
```

## 代码阅读入口

- `input-layer.js`：输入层最小版，默认单角色，从本地 EVE 日志读取角色名、当前星系，并尝试读取舰队频道。
- `assembler.js`：逻辑层的信息组装器，只负责生成轻量求救文本。
- `app.js`：页面交互和剪贴板复制。
- `alert-correlator.js`：预警关联器原型，暂时保留，当前轻量版不作为核心路径。
- `esi-input-adapter.js`：ESI 输入适配器占位，当前轻量版不作为核心路径。

## 输入层测试

在项目目录中运行：

```powershell
node input-layer.js
```

它会读取：

```text
C:\Users\<你的用户名>\Documents\EVE\logs\Chatlogs
C:\Users\<你的用户名>\Documents\EVE\logs\Gamelogs
```

当前版本默认本机只有一个角色账号：

- 从最新的 `本地_*.txt` 中提取当前星系。
- 从日志头的 `Listener` / `收听者` 提取被抓人员 ID。
- 从舰队相关 chatlog 中尝试提取所在舰队；找不到时输出 `未知`。

## Web 最小版限制

浏览器不能在未授权的情况下自动读取本地文件，所以当前 Web 版需要用户手动选择日志文件。选择后，后续组装和复制都是一键完成。
